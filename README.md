# GitHub and AI Workflow Practice

## Purpose

This repository documents my practice using GitHub Issues, feature branches, meaningful commits, pull requests, reviews, and responsible AI assistance.

## Learning objectives

Through this assignment, I will demonstrate how to:

- Use a GitHub Issue to define work and observable acceptance criteria.
- Develop changes on a feature branch instead of directly on the default branch.
- Organize related work into meaningful commits.
- Document how AI assistance was accepted, revised, or rejected.
- Open, review, and merge a pull request.
- Verify the completed workflow using repository history and GitHub links.

## Repository contents

- `README.md` explains the purpose and scope of the repository.
- `workflow-notes.md` documents the GitHub workflow and supporting links.
- `ai-log.md` records AI interactions and my decisions about the suggestions.

## Planned workflow

1. Define the assignment using GitHub Issue #1.
2. Complete the documentation on `feature/github-ai-workflow`.
3. Publish the feature branch to GitHub.
4. Open and review a pull request.
5. Merge the approved work into `main`.
6. Retain the feature branch as evidence of the workflow.
